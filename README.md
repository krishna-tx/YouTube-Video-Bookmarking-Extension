# YouTube-Video-Bookmarking-Extension


## Instructions for Installing the Extension to Chrome:
* Clone the Git Repo onto your personal computer
* On Chrome, click on the 3 dots on the upper right -> hover your mouse over "Extensions" -> click "Manage Extensions"
* On the "Manage Extensions" page, toggle the "Developer mode" on the upper right to on
* Click on the "Load unpacked" button on the upper left and select the project folder
* Pin the extension's icon onto the extensions bar in Chrome for ease of use
