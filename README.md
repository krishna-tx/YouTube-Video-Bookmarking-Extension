# YouTube Video Bookmarking Extension

## About the Project
In my free time, I like to watch different podcasts or musical concerts for entertainment and relaxation. I also happen to have this habit of going back and rewatching parts of videos I have already watched before. However, since these YouTube videos are quite long, it makes scrolling to different timestamps very tedious and time-consuming. Realizing this issue I was having, I decided to create an extension that saved my time and frustration. 

Similar to how we can place bookmarks or note down the page numbers in a book, this extension allows the user to store different timestamps of a YouTube video to quickly go back to them whenever they please.

## Instructions for Installing the Extension in Chrome
1. Clone the Git Repo onto your personal computer
2. On Chrome, click on the 3 dots on the upper right -> hover your mouse over "Extensions" -> click "Manage Extensions"
3. On the "Manage Extensions" page, toggle the "Developer mode" on the upper right to on
4. Click on the "Load unpacked" button on the upper left and select the project folder
5. Pin the extension's icon onto the extensions bar in Chrome for ease of use

## Instructions for How to Use the Extension
1. Click on the extension's icon to open up the pop-up to reveal existing bookmarks
2. On a YouTube video, select the timestamp you want to save a bookmark at and click the "Add a Bookmark" button
3. By default, the name of the bookmark is just the timestamp itself, and the extension sorts the bookmarks in chronological order
4. To change the name of the bookmark, select the text box, change the name, and HIT ENTER (otherwise the extension will not register the name change)
